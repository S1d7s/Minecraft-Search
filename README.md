## 🎯 Sobre o Projeto

**Minecraft Search** é um mecanismo de busca simples e intuitivo que permite pesquisar rapidamente informações sobre itens, mobs, dimensões e muito mais do universo Minecraft.

### ✨ Funcionalidades

- 🔍 **Busca em tempo real** - Resultados aparecem enquanto você digita
- 🌙☀️ **Tema escuro/claro** - Alternância com persistência local
- 📱 **100% responsivo** - Funciona perfeitamente em celular, tablet e PC
- ⚡ **Leve e rápido** - Zero dependências, puro HTML+CSS+JS
- 🎨 **Design moderno** - Interface limpa inspirada no Google
- 📂 **Fácil de expandir** - Adicione novos dados via JSON
